# Assets and provenance

- Narration, original prototype recordings, PPTX/PDF/HTML: supplied Team C-10 / teamGARI project assets.
- Background and abstract-avatar concepts: generated using the available OpenAI image-generation tool for this project. The tool did not expose a DALL·E 3 model selector.
- Transparent geometric avatars: production derivative of the generated art-direction reference; their names are labels for the speakers, not depictions of their faces.
- Inter Variable: the Inter project / Rasmus Andersson. Source: https://github.com/rsms/inter . Its license is included at `public/assets/fonts/LICENSE-Inter.txt`.
- Procedural sound accents, graphics, animation and source code: prepared for this project with OpenAI Codex assistance.
- HCI research references are listed in `src/data/config.ts`, the rendered credits and the original supplied documents. Vendor marketing and preprint material are identified separately from peer-reviewed research.

The project source is a private handoff (`private: true` in package.json). This document does not relicense the team's supplied assets or third-party materials.
